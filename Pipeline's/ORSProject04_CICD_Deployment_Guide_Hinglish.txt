ORSProject04 CI/CD DEPLOYMENT GUIDE
GitHub -> Jenkins (Windows) -> Docker Desktop -> Docker Hub -> AWS EC2
Language: Hinglish

============================================================
1. PROJECT FLOW
============================================================

1. Source code GitHub par store hota hai.
2. Jenkins GitHub se source code checkout karta hai.
3. Maven ORSProject04.war file build karta hai.
4. Docker Desktop Jenkins machine par application image banata hai.
5. Jenkins image ko tag karke Docker Hub par push karta hai.
6. Jenkins SSH ke through AWS EC2 se connect karta hai.
7. EC2 Docker Hub se latest application image pull karta hai.
8. EC2 ORS application container run karta hai aur existing MySQL container se connect karta hai.
9. Browser mein application open karke login test kiya jata hai.

IMPORTANT DETAILS:
- Jenkins URL: http://localhost:8085
- GitHub repository: https://github.com/lakhan-porwal/ORSProject04-Complete.git
- Branch: main
- Project folder: ORSProject04
- Docker Hub image: lakhanporwal/orsproject04:latest
- Jenkins Docker Hub credential ID: docker-creds-new
- Jenkins AWS SSH credential ID: aws-ec2-ssh
- EC2 public IP Stop/Start ke baad change ho sakta hai. AWS Console se current IP check karo.

2. AWS EC2 INSTANCE CREATE KARNA
============================================================

1. AWS Console open karo aur EC2 par jao.
2. Launch instance par click karo.
3. Instance ka naam rakho: ORSProject04-Server-New
4. Ubuntu Server 24.04 LTS (64-bit x86) select karo.
5. Account mein available suitable instance type select karo, jaise t3.micro.
6. Key pair create ya select karo: ORS-deploy-key
7. .pem file download karke safe jagah rakho. Is file ko GitHub par upload mat karna.
8. Instance launch karo.
9. Launch hone ke baad security group configure karo.
10. Instance Running ho aur status checks pass hon, tab aage badho.

IMPORTANT:
- Troubleshooting ke liye instance ko terminate mat karna.
- Stop aur Terminate alag actions hain.
- Terminate karne se instance permanently delete ho sakta hai.

============================================================
3. SECURITY GROUP RULES
============================================================

AWS Console mein:
EC2 -> Instances -> apna instance -> Security -> Security Group
-> Inbound rules -> Edit inbound rules

Rules:
A. SSH
- Port: 22
- Source: My IP (recommended)

B. HTTP
- Port: 80
- Source: 0.0.0.0/0
- Sirf tab jab application port 80 par serve ho.

C. HTTPS
- Port: 443
- Source: 0.0.0.0/0
- Sirf tab jab HTTPS configure ho.

D. Custom TCP
- Port: 8080
- Source: 0.0.0.0/0
- Tomcat application ko browser se access karne ke liye.

E. MySQL port 3308 (optional)
- Sirf trusted IP se direct MySQL access ki zaroorat ho tab.
- MySQL ko public internet par expose mat karo. App Docker network ke through MySQL se connect hoti hai.

============================================================
7. MYSQL SETUP AUR DATA PRESERVE KARNA
============================================================

Existing details:
- Database: p04
- Container: mysql-container
- Image: lakhanporwal/mysql:8.0
- Network: ors-network

Pehle existing setup check karo:

sudo docker ps -a
sudo docker volume ls
sudo docker network inspect ors-network

Agar existing mysql-container aur database data present hai to use sirf deployment ke liye delete ya recreate mat karo.

FRESH DATABASE SETUP ONLY:
Persistent volume create karo:
sudo docker volume create mysql-data

MySQL container run karo:
sudo docker run -d --restart unless-stopped --name mysql-container --network ors-network --network-alias mysql -p 3308:3306 -e MYSQL_ROOT_PASSWORD=root -e MYSQL_DATABASE=p04 -v mysql-data:/var/lib/mysql lakhanporwal/mysql:8.0

IMPORTANT:
- Upar wali command sirf fresh database setup ke liye hai.
- Existing mysql-container ke upar ise mat chalana.
- Existing container ya volume delete karne se database data loss ho sakta hai.
- Production mein strong passwords aur secure secrets use karo.

Agar existing MySQL container network se connected nahi hai:
sudo docker network connect --alias mysql ors-network mysql-container

Agar container stopped hai:
sudo docker start mysql-container

Databases check:
sudo docker exec mysql-container mysql -uroot -proot -e "SHOW DATABASES;"

Expected database: p04

Connection test:
sudo docker exec mysql-container mysql -uroot -proot -D p04 -e "SELECT 1 AS connection_test;"

App container banne ke baad hostname check:
sudo docker exec ors-container getent hosts mysql

12. COMPLETE JENKINSFILE
============================================================

Is Jenkinsfile ko ORSProject04/Jenkinsfile mein save kar sakte ho, agar yahi tumhare repository mein exact path hai.

IMPORTANT BEFORE RUNNING:
- AWS_HOST ko EC2 ke current public IP se replace karo.
- Jenkins credentials docker-creds-new aur aws-ec2-ssh pehle se configure hon.
- EC2 par Docker installed aur running ho.
- MySQL container aur ors-network pehle se correctly configured hon.
- Ye pipeline app container replace karne ke liye hai; MySQL container/volume delete nahi karna.
- Network alias already attached hone par network connect command fail ho sakti hai. Neeche diya gaya SSH command is case mein error handling ko reliably handle nahi karta. Production ya important data wale server par use karne se pehle deployment stage ko safer commands mein split aur test karna chahiye.

pipeline {
    agent any

    environment {
        DOCKER_IMAGE = 'orsproject04'
        DOCKERHUB_IMAGE = 'lakhanporwal/orsproject04:latest'
        AWS_HOST = 'YOUR_EC2_PUBLIC_IP'
    }

    stages {
        stage('Git Checkout') {
            steps {
                git branch: 'main',
                    url: 'https://github.com/lakhan-porwal/ORSProject04-Complete.git'
            }
        }

        stage('Build WAR') {
            steps {
                dir('ORSProject04') {
                    bat 'mvn clean package'
                }
            }
        }

        stage('Build Docker Image') {
            steps {
                dir('ORSProject04') {
                    bat 'docker build -t %DOCKER_IMAGE%:latest .'
                }
            }
        }

        stage('Tag Docker Image') {
            steps {
                bat 'docker tag %DOCKER_IMAGE%:latest %DOCKERHUB_IMAGE%'
            }
        }

        stage('Push to Docker Hub') {
            steps {
                withCredentials([
                    usernamePassword(
                        credentialsId: 'docker-creds-new',
                        usernameVariable: 'DOCKER_USER',
                        passwordVariable: 'DOCKER_PASS'
                    )
                ]) {
                    bat '''
                        @echo off
                        echo %DOCKER_PASS% | docker login -u %DOCKER_USER% --password-stdin
                        if errorlevel 1 exit /b 1
                        docker push %DOCKERHUB_IMAGE%
                        if errorlevel 1 exit /b 1
                        docker logout
                    '''
                }
            }
        }

        stage('Deploy to AWS') {
            steps {
                withCredentials([
                    sshUserPrivateKey(
                        credentialsId: 'aws-ec2-ssh',
                        keyFileVariable: 'SSH_KEY',
                        usernameVariable: 'SSH_USER'
                    )
                ]) {
                    bat '''
                        @echo off
                        ssh -i "%SSH_KEY%" -o StrictHostKeyChecking=no %SSH_USER%@%AWS_HOST% "sudo docker pull %DOCKERHUB_IMAGE% && sudo docker start mysql-container && sudo docker network connect --alias mysql ors-network mysql-container 2>/dev/null || true && sudo docker rm -f ors-container 2>/dev/null || true && sudo docker run -d --restart unless-stopped --name ors-container --network ors-network -p 8080:8080 %DOCKERHUB_IMAGE%"
                        if errorlevel 1 exit /b 1
                    '''
                }
            }
        }

        stage('Verify Containers') {
            steps {
                withCredentials([
                    sshUserPrivateKey(
                        credentialsId: 'aws-ec2-ssh',
                        keyFileVariable: 'SSH_KEY',
                        usernameVariable: 'SSH_USER'
                    )
                ]) {
                    bat '''
                        @echo off
                        ssh -i "%SSH_KEY%" -o StrictHostKeyChecking=no %SSH_USER%@%AWS_HOST% "sudo docker ps"
                    '''
                }
            }
        }
    }

    post {
        success {
            echo 'ORSProject04 CI/CD pipeline completed successfully.'
        }
        failure {
            echo 'Pipeline failed. Review the failing stage in Console Output.'
        }
    }
}
